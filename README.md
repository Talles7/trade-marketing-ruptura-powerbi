# 📊 Trade Marketing | Vendas e Ruptura

Projeto desenvolvido em Power BI com foco em **análise de negócio aplicada a um cenário de Trade Marketing**.

A proposta foi praticar minha capacidade de partir de uma base de dados, entender o contexto do negócio e transformar os dados em **indicadores e análises que ajudassem a identificar problemas e direcionar decisões**.

## Sobre o projeto

Trabalhei com um cenário de vendas no varejo em que um dos principais pontos de análise era a **ruptura de produtos**.

Estruturei o dashboard para começar pela visão geral do negócio e depois aprofundar a análise por período, loja e produto.

Os principais indicadores foram:

- **25 mil** unidades vendidas
- **R$ 215,76 mil** em faturamento
- **37** ocorrências de ruptura
- **3,9%** de ruptura no período

## 🔎 Análise

Na evolução mensal, **maio apresentou o maior índice de ruptura, com 6,20%**.

Ao detalhar por loja, **Mercado Recife (7,02%) e Hiper Barueri (6,90%)** apresentaram os maiores percentuais, indicando pontos que merecem uma investigação mais aprofundada.

Também relacionei **Faturamento Total x Ruptura % por Produto**.

Essa comparação foi importante para não olhar a ruptura isoladamente. Além de identificar os produtos com maior percentual, consegui observar sua relevância financeira e, com isso, ter mais contexto para definir quais situações poderiam ser priorizadas pelo negócio.

O dashboard permite identificar **onde e quando a ruptura está acontecendo**, mas não foi utilizado para assumir suas causas. Um aumento de ruptura pode exigir uma investigação posterior envolvendo estoque, reposição, distribuição ou execução no ponto de venda.

## 💡 Resultado

Mais do que praticar a construção de dashboards, este projeto foi uma forma de desenvolver meu raciocínio analítico.

Parti de um cenário de negócio, defini quais perguntas queria responder, organizei os dados e construí indicadores que permitissem sair de uma visão geral até pontos específicos que mereciam investigação.

O principal exercício foi justamente transformar **dados organizados em informação voltada para o negócio**, utilizando o Power BI como ferramenta para apoiar essa análise.
